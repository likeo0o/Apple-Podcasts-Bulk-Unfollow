# Apple Podcasts Bulk Unfollow

[English instructions](README.en.md) · [代码与风险审查](docs/CODE_REVIEW.md) · [MIT 许可证](LICENSE)

通过 macOS 辅助功能，向 Apple Podcasts 中的节目发送批量取消关注请求。适合想整理自己关注列表、愿意检查界面与源码的 Mac 用户。

**实验性工具。默认仅处理 1 个节目，运行前需要确认；分享版未做真实取消关注测试。** 它依赖英文界面的 `Shows` 分组和 `Unfollow` 菜单项，不保证适用于其他语言、其他 macOS 版本或所有节目视图。

## 先了解影响

- 取消关注会改变资料库，可能通过 Apple 的资料库同步影响其他设备。先自行记录要保留的节目名称或链接；本项目不提供备份、撤销或一键恢复。
- Apple Podcasts 可能询问保留还是移除下载的单集。分享版遇到可识别的弹窗就停止，**不自动点击移除、删除或保留按钮**。请自行读完提示再决定。停止前最后一次请求可能已经生效。
- 取消关注不等于取消付费订阅，也不等于删除全部收听历史。[Apple 官方说明](https://support.apple.com/en-mt/guide/podcasts/podf17151dc/mac)明确区分取消关注、付费订阅和下载内容选择。
- 请始终看着 Podcasts 界面。界面变化、辅助功能元数据错误或同步延迟仍可能导致操作异常；这些保护措施不构成内容保留保证。

## 下载与准备

1. 在本仓库选择 **Code → Download ZIP**，解压；或使用 Git 克隆仓库。无需安装 Python、Node 或其他依赖。
2. 先阅读脚本和本文。打开 Apple Podcasts，手动进入 **Library → Shows**；如有筛选，选择仅显示已关注节目。关闭其他 Podcasts 窗口、迷你播放器和弹窗，保持一个主窗口。
3. 本版只匹配英文界面标签。其他语言暂不支持。可以在系统支持的“语言与地区 → 应用程序”中单独设置 Podcasts 为 English，然后重新打开应用；不必更改整台 Mac 的语言。
4. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许实际运行脚本的应用，例如“终端”或“脚本编辑器”。系统如提示自动化权限，仅按需要允许该应用控制 System Events / Podcasts。名称和位置可能随 macOS 变化，参见 [Apple 辅助功能权限说明](https://support.apple.com/guide/mac-help/allow-accessibility-apps-to-access-your-mac-mh43185/mac)。无需管理员命令、完全磁盘访问或关闭系统保护。

## 使用：先只处理一个节目

在“终端”输入 `cd `（末尾留空格），把解压后的项目文件夹拖入终端，按回车。然后运行：

```sh
osascript ./unfollow_all_podcasts.applescript
```

这条命令**会开始真实操作**，不是预览。确认对话框默认选择 Cancel；选择 Continue 后，最多发送 1 次请求。也可以在“脚本编辑器”中打开分享版并点击运行，同样默认上限 1。

亲自确认结果符合预期后，可自行决定是否运行小批量，例如最多 10 次：

```sh
osascript ./unfollow_all_podcasts.applescript 10
```

参数只接受 `1` 至 `500` 的整数；每次运行都会再次确认。上限限制的是请求数，**不保证一次清空全部关注**。

运行期间不要点击、切换 Podcasts 的页面或进行其他操作。需要中止时，在启动命令的终端按 **Control-C**，或点击脚本编辑器的停止按钮；已经发送的请求不会撤回。程序停止后检查 Podcasts 是否留有菜单或弹窗，并手动处理。

## 输出与故障排查

终端显示已发送的请求数及停止原因，不把点击次数当作成功取消关注数。节目标签可能显示在本地终端日志中；分享日志前请自行检查隐私。

- **找不到 Shows / Unfollow**：检查应用语言、Library → Shows 页面和关注筛选；如果仍失败，该 UI 版本暂不支持。不要改成匹配 `Remove` 或自动点击默认按钮。
- **发现弹窗**：脚本会停止。人工决定保留还是移除下载，确认当前节目状态，再重新运行。没有“自动继续”或自动删除模式。
- **第一张节目卡片未变化 / 标签重复**：为避免重复点击而停止。显示所有节目时，已取消关注的节目可能仍保留在资料库；先检查筛选和结果。
- **权限错误**：核对实际运行宿主的辅助功能和自动化权限，必要时退出并重新打开该宿主。
- **窗口数量、焦点或搜索预算错误**：保持单个主窗口。脚本无法处理任意界面结构；不要通过提高批量上限解决兼容性问题。
